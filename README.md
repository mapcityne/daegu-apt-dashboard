# 아파트 실거래가 시장 신호 (전국)

전국 256개 시군구 아파트 매매 실거래가로 **지금 오르는지 내리는지**와 **왜 그런지**를 한 화면에서 보여 준다.

서비스: https://daegu-apt.streamlit.app

## 화면

- **방향 신호**: 지역마다 ▲상승 / ■보합 / ▼하락. 같은 단지·같은 면적만 비교한 *동일단지 가격지수*의
  최근 3개월 평균이 직전 3개월보다 +1% 이상이면 상승, −1% 이하면 하락.
- **하위 지역 신호**: 전국→시도, 시도→시군구, 시군구→법정동 순으로 내려가며 비교.
- 탭: 🧭 자동 브리핑 · 🗺️ 시군구 색지도 · 📈 지수 추이 · 🏆 TOP·상승하락 · 🔥 신고가·전고점 · 💰 예산으로 찾기 · 🏢 단지 상세

### 자동 브리핑 구성
1. 시장 전체 (지수 변동, 거래량, 상승 단지 비율, 구성 효과)
2. 하위 지역 차별화 (강세·보합·약세)
3. **왜 오르나·내리나** — 실거래로 본 주도 요인: 신축/구축, 면적 쏠림, 상승의 폭(소수 단지 vs 광범위),
   거래 동반 여부, 신고가 확산, 고가 거래 비중, 상승 주도 단지·대장 단지
   + 공공통계로 본 수요·공급 요인: 미분양 증감(시군구), 인구 순유입·유출(시군구), 아파트 입주 물량(시도)
4. 신축 쏠림 5. 면적별 6. 매수자 참고 수치

## 구조

| 파일 | 역할 |
|---|---|
| `collect.py` | 국토부 실거래가 API 직접 호출. 시군구×월 캐시, 최근 달부터, 병렬, 한도 초과 시 다음 날 이어받기 |
| `build.py` | 지역 재배정(2026.7 개편) → 시도별 거래, 지역 통계·지수·브리핑 재료(`data/out`) |
| `analysis.py` | 동일단지 지수, 변동률, 신고가, 주도 요인 분석 |
| `briefing.py` | 브리핑 문장 생성 |
| `kosis.py` | KOSIS 미분양(시군구)·인구이동(시군구)·아파트 준공(시도) 수집 |
| `app.py` | Streamlit 앱. `data/out`이 없으면 GitHub Release `data`에서 내려받음 |
| `regions.py`, `geo/` | 2026.10 기준 시도·시군구 코드와 경계 |

## 운영

- GitHub Actions `update-data`가 매일 03:17(KST)에 수집 → 집계 → Release `data` 업로드.
- 첫 전국 수집은 약 1만 회 호출이라 일일 한도에 걸리면 다음 날 자동으로 이어받는다. 앱 사이드바에 진행률 표시.
- 필요한 Secrets: `DATA_GO_KR_KEY` (공공데이터포털 「국토교통부_아파트 매매 실거래가 상세 자료」), `KOSIS_KEY` (KOSIS 공유서비스)

## 로컬 실행

```bash
pip install -r requirements-collect.txt -r requirements.txt
DATA_GO_KR_KEY=... python collect.py --sido 27 --months 36   # 대구만
python build.py
streamlit run app.py
```

## 기준·유의사항

- 해제 거래 제외, 직거래 기본 제외. 평당가 = 거래금액 ÷ (전용면적 ÷ 3.3058).
- 거래량은 신고 기한(계약 후 30일) 때문에 기준월 직전 3개월로 전년 동기와 비교.
- 2026.7 행정구역 개편(인천 구 개편, 전남광주통합특별시, 화성·부천 일반구) 반영. 옛 코드 거래는 법정동으로 새 시군구에 재배정.
- '전고점'은 수집기간(최근 36개월) 안의 최고가.
